# CodeAlpha_BasicChatbot

**CodeAlpha Python Programming Internship — Task 4**

A simple rule-based chatbot that responds to greetings and a few common
phrases with predefined replies.

## How to run
```bash
python chatbot.py
```

## Features
- Keyword-based matching (hello, how are you, your name, jokes, thanks, bye)
- Multiple varied replies per keyword for a more natural feel
- Graceful fallback for unrecognized input
- Exits automatically when the user says 'bye' or 'goodbye'

## Concepts used
`if-elif` logic (via dictionary lookup), functions, loops, input/output.
